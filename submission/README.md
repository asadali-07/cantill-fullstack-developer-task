# Blind Test Submission Folder

This directory stores the three required CSV export files generated during the blind test window:

1. `yourname__run1.csv` — PR batch decision results executed against Corvo Policy v5.0.
2. `yourname__run2.csv` — PR batch decision results executed against the amended policy (e.g., v5.1).
3. `yourname__preferred.csv` — Ranked preferred suppliers export generated as of November 1, 2026.

### How to Generate via the Application:
1. **Run 1:** Open the Buyer Workspace at `/workspace`, upload the blind test PR batch CSV, click **Export Decisions CSV**, and name it `yourname__run1.csv`.
2. **Amend Policy:** Navigate to `/policy`, paste or upload the policy amendment memo, click **Preview Amendment Diff**, review the AI-parsed changes, and click **Approve & Activate**.
3. **Run 2:** Return to `/workspace`, re-run the batch, click **Export Decisions CSV**, and name it `yourname__run2.csv`.
4. **Preferred Suppliers:** Click **Export Preferred Suppliers** on `/workspace`, and name it `yourname__preferred.csv`.
